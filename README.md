A Jankx Framework extension that enables rich media attachments—including images, audio, and video—in WordPress comments.

---

A powerful media attachment extension for the **Jankx Framework**. This plugin enhances the default WordPress commenting system by allowing users to upload and attach images, video files, and other rich media directly within their comments, delivering a modern and engaging user interaction experience.

**Key Features:**

* **Rich Media Attachments:** Allows users to attach images, videos, or audio directly to WordPress comments.
* **Seamless Integration:** Native, lightweight integration designed specifically for the Jankx Framework ecosystem.
* **AJAX File Uploads:** Fast and asynchronous media uploading without refreshing the page.
* **Media Management & Security:** File type validation, size restrictions, and secure processing for user-uploaded content.
* **Responsive Layout:** Optimized display for attachment previews across desktop and mobile devices.
